# Boceteador de Logos

Webapp para armar bocetos de logos sobre productos promocionales: elegís un
producto, subís tu logo, lo ubicás en la zona imprimible y descargás el boceto
en PNG/PDF. Funciona standalone y también embebida (iframe/widget) en
cualquier sitio.

📄 **El diseño completo está en [DESIGN.md](./DESIGN.md)** — flujos, modelo de
datos, editor canvas, modo embebible, stack propuesto y roadmap.
